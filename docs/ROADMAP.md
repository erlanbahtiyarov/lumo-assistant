# План завершения Лумо

## Реализовано

- [x] Отдельный репозиторий Lumo с историей исходного проекта.
- [x] Нативный интерфейс Qt Widgets, ввод текста, история и обратная связь.
- [x] Питомец: округлое тело с плоским основанием, взгляд прямо, моргание и реакции.
- [x] Общий тёмный стиль окна, настроек и виджета по направлению Nusa/Coucou.
- [x] Прямоугольная рамка без текста в ожидании; панель при наведении или работе.
- [x] Привязка к четырём краям, положение вдоль края, сохранение монитора.
- [x] Перетаскивание, закрепление, размер, видимость, положение и «поверх окон».
- [x] Фоновая запись/ASR, предел времени, тишина, остановка и удаление временного аудио.
- [x] Настройки микрофона, моделей, горячей клавиши, приложений, папок и питомца.
- [x] Консервативная проверка отрицаний, неполных и составных команд.
- [x] Согласованные объекты и глаголы открытия, отказ при коллизии алиасов.
- [x] Одноразовое подтверждение конкретного действия с TTL и отменой.
- [x] Нейросетевые предложения требуют подтверждения и проверки allowlist.
- [x] Подключение локального Ollama через структурированные ответы.
- [x] Профиль пользователя, пакетные конфиги, wheel и CLI-диагностика.
- [x] Новое разбиение 64/11/11, проверка аудиофайлов и единый split для тренеров.
- [x] Словарь текстового восстановления строится по train, сохраняется лучшая validation-модель.
- [x] Автотесты ядра, микрофона с подменой оборудования и сценариев Qt.
- [x] Workflow Windows/Linux и рецепт сборки Windows-приложения.
- [x] Настоящие пути Windows Known Folders для нового профиля, включая «Видео».
- [x] Системный браузер либо отдельный ручной выбор; обновление системного при запуске.
- [x] Поиск приложения в App Paths/PATH и стандартной папке Telegram.
- [x] Обновление только выбранного пути через настройки, без перезаписи остальных.
- [x] Фоновая проверка готовности в Qt и общий отчёт CLI doctor.

## До признания дипломного проекта законченным

- [ ] Проверить физический микрофон, глобальную клавишу, прозрачный виджет и
      реальные действия в целевой Windows, включая перенесённые пользовательские папки.
- [ ] Испытать собранный Lumo.exe на машине без Python и без заранее загруженных моделей.
- [ ] Выбрать окончательные Whisper и модель понимания на измерениях качества,
      задержки и потребления памяти на целевом компьютере.
- [ ] Добавить записи настоящих пользователей, шум/тишину/отрицания/неизвестные
      фразы и независимые голоса; прослушать и проверить автоматическую разметку.
- [ ] Расширить класс скриншота: единственную запись нельзя независимо оценить.
- [ ] Оценить точность объектов и полного действия, а не только intent.
- [ ] Откалибровать отказы/уточнения нейросети на достаточной контрольной выборке.
- [ ] Уточнить роль Audio CNN: сравнение моделей либо дальнейшее подключение.
- [ ] Подготовить окончательные таблицы, отчёт экспериментов и сценарий защиты.

## Последний этап — Linux

GUI, питомец, ASR и dry-run уже используют общий код. Реальное выполнение
действий в Linux намеренно закрыто до реализации отдельного исполнителя и
проверки X11/Wayland. Позиционирование виджета и глобальные горячие клавиши
необходимо проверить отдельно для целевого окружения.

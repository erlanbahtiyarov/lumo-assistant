# Лумо: план завершения дипломного проекта

Тема: «Разработка настольного голосового помощника „Лумо“ с нейросетевой
интерпретацией команд и анимированным персонажем».

## 1. Основа и надёжное выполнение

- [x] Название Lumo, отдельный локальный репозиторий с историей M_O и команда `lumo`.
- [x] Отказ для пустых и однословных фраз, явных отрицаний и соединённых команд.
- [x] Открытие разрешённых приложений/папок с разными глаголами и алиасами.
- [x] Защита распознанной команды от перезаписи моделью восстановления.
- [x] Проверка согласованности intent после восстановления, сохранение исходного текста.
- [x] Создание artifacts при первой записи, отложенный импорт GUI для CLI.
- [x] Соблюдение allow_download для Whisper.
- [ ] Перенести историю и изменения в GitHub после настройки доступа.
- [ ] Подтверждение конкретного опасного действия с отменой и сроком действия.
- [ ] Понятные ошибки ОС/микрофона и контроль обязательных параметров.
- [ ] Проверка установки, конфигурационных ресурсов и моделей на чистой Windows.

Ограничение текущей защиты: это консервативные правила для одиночных команд,
а не универсальное понимание русского языка. Отказ предпочтителен для неоднозначной фразы.

## 2. Собственное настольное приложение

- [ ] Собственный GUI без браузера и web-оболочки; текущая заглушка будет заменена.
- [ ] Микрофон, горячая клавиша, запись, состояния обработки и история результатов.
- [ ] Настройки моделей, команд, путей приложений и папок; явный режим выполнения.
- [ ] Вывод «Что услышал» / «Что будет сделано» и запрос уточнения.

## 3. Питомец Лумо

- [ ] Собственный персонаж: маленький чёрный шарик с большими глазами.
- [ ] Виджет с перетаскиванием, закреплением и сохранением положения.
- [ ] Размер, видимость, настройка «поверх окон».
- [ ] Анимации ожидания, прослушивания, обработки, успеха и ошибки.

## 4. Нейросеть и доказательство качества

- [ ] Согласовать каталог команд, объекты и разметку.
- [ ] Разделить train/val/test с покрытием классов и независимыми голосами.
- [ ] Добавить реальные голоса, шум, тишину, отрицания и неизвестные команды.
- [ ] Сравнить правила, ASR+правила и ASR+восстановление на общей выборке.
- [ ] Решить роль экспериментальной Audio CNN; сейчас она не подключена к приложению.
- [ ] Измерить точность полного действия, ложные действия и задержку.

## 5. Выпуск и Linux

- [ ] Windows CI, сборка, документация, демонстрация и воспроизводимый отчёт.
- [ ] Отделить платформенные действия от общих ASR/NLU и GUI.
- [ ] После готовности Windows реализовать Linux и проверить виджет в целевом окружении.

Критерий готовности первой версии: чистая установка на Windows, рабочий сценарий
«запись → понимание → проверенное действие», собственный интерфейс и питомец,
отказ на неподдерживаемой речи, подтверждение опасных действий и измеренный результат.

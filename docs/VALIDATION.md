# Проверка версии 0.2

Дата: 2 ноября 2026. Локальная среда: Linux, Python 3.12.16, Qt/PySide6 6.12.

## Приложение

Автотесты проверяют интерпретацию, отказы, allowlist, коллизии алиасов,
одноразовое подтверждение/отмену/TTL, ошибки выполнения, очистку аудио,
настройки, историю, контроль качества split и native Qt-сценарии.

Qt-сценарии запускаются с QT_QPA_PLATFORM=offscreen, нажимают настоящие кнопки
и дожидаются фоновых задач. Микрофон и ASR в этих тестах подменяются.
Это не испытание физического устройства, оконного менеджера или действий Windows.

Скриншоты в docs/images получены из работающих Qt-окон приложения.
Wheel собирается с конфигурациями и проверяется отдельно от исходной папки.

## Реальная ASR-проверка

Выполнено распознавание MP3 из корпуса через Faster-Whisper tiny (CPU/int8),
без подмены модели. Первая запись распознана как «Открой папку загрузки».
При первом запуске обнаружена несовместимость PyAV 19 с faster-whisper 1.2.1:
параметр metadata_errors удалён из av.open. После ограничения PyAV <17
проверка прошла с av 16.1.0. Версии зафиксированы в requirements-desktop.lock.

Контрольная выборка содержит только 11 синтезированных записей. Метрики этого
пилотного эксперимента не следует переносить на реальные голоса. Класс
скриншота отсутствует в holdout: его единственный пример оставлен в train.

Отчёты воспроизводятся скриптом scripts/evaluate_pipeline.py. Они измеряют
intent, а не правильность всех объектов и реальное выполнение ОС. Подтверждение
нейросетевых предложений в эксперименте не выдаётся: сервис возвращает предложение.

## Что остаётся проверить

- Физический микрофон и работа Windows API на целевом компьютере.
- Установка и запуск Windows-артефакта на чистой машине.
- Независимая оценка точности и задержки выбранной локальной языковой модели.
- Независимая выборка реальных голосов, шум, неизвестная речь и ошибки объектов.
- Позиционирование/прозрачность виджета в целевых Windows и Linux/Wayland.

## Результаты пилотной проверки

Локально проходят **76 автоматических тестов**, Ruff и валидатор 86 записей.
Проверены wheel в отдельном окружении и настоящее распознавание MP3. Windows CI
также собирает Lumo.exe и запускает встроенный smoke-test окна и Qt event loop;
это не тест микрофона, клавиатурных действий и выключения системы.

| Конвейер на 11 записях test | Правильный intent / отказ | Ложные предложения для unknown | Медиана времени |
|---|---:|---:|---:|
| Whisper small + правила | 6/11 | 0 | 1,29 с |
| Whisper small + правила + Qwen3:1.7b и проверки | 11/11 | 0 | 1,85 с |

Время не включает загрузку Whisper; Ollama был прогрет предыдущими запросами.
Результаты включают отказ для неизвестного намерения. Объекты и реальное
выполнение не оценивались этой таблицей. Полные предсказания сохранены в
[experiments/small-rules.json](experiments/small-rules.json) и
[experiments/small-local-llm.json](experiments/small-local-llm.json).

**Эти записи просматривались при отладке.** В ходе разработки модель ошибочно
предлагала закрыть окно вместо неподдерживаемого переключения окон. Добавлены
проверки исходного текста для разрушающих действий и регрессионные тесты.
Модель также выдавала правильное намерение с произвольной уверенностью 0:
поэтому самооценка удалена из схемы ответа. Все предложения нейросети остаются
подтверждаемыми. Результат 11/11 — проверка работоспособности на малом знакомом
корпусе, а не доказательство 100% точности на независимой речи.

В отдельном наборе из девяти ручных сценариев проверены свободные просьбы,
опечатка, отрицание, вопрос о действии, составная команда и неизвестная речь.
Результат: **9/9** после добавления проверок; это тоже разработческие сценарии,
а не независимый бенчмарк. [Полный отчёт](experiments/semantic-scenarios.json).
